# Intelligent Job Matching & Interview Platform

A recruitment platform that goes beyond basic job-board CRUD: it parses resumes and job descriptions into structured data, computes an **explainable** candidate-job match score (not just a black-box percentage), and runs the full application-to-interview workflow.

## Problem
Most job portals just store listings and applications. This platform demonstrates real software engineering: structured data extraction, a transparent matching algorithm, role-based security, and a complete recruitment workflow — from profile to interview.

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB (Atlas)
- **Auth:** JWT
